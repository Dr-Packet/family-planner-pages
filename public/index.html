Family Planner

A simple, shared home dashboard for family routines, schedules, chores, rewards, allowances, and daily planning.

Privacy Policy Terms

Included features

  • Google sign-in for secure family access
  • Google Calendar integration
  • Shared family schedules and routines
  • Chores and reward tracking
  • Allowance and household planning

Google sign-in

Family Planner uses Google authentication for secure sign-in and a familiar login experience. This public site is only a landing page and does not handle sign-in itself.

Google Calendar integration

Family scheduling can be connected to Google Calendar so events, routines, and reminders stay aligned with the household calendar.

Public documentation

This website exists to satisfy Google OAuth and privacy requirements for a public-facing app profile. The actual application remains private behind a home network and Tailscale access.
