Privacy Policy

Family Planner is a private household planning application intended for routines, chores, allowance tracking, rewards, and shared family scheduling. This public site provides project information and legal notices. The actual Family Planner application is not publicly hosted here.

This notice is written conservatively and states only information that is generally described for the project. The owner must confirm the final production configuration before publishing a final legal privacy policy.

1. Information the app may access through Google

If Google sign-in is enabled, the application may use Google account information returned by the OAuth sign-in flow, such as a Google user identifier, email address, and basic profile information made available to the app by Google.

If Google Calendar access is enabled, the app may request access to calendar data in order to view or manage family schedule information. The exact scopes and fields used must be confirmed by the application owner before publication of a final policy.

2. Why Google data is used

Google sign-in is used for account authentication and user identification within the private Family Planner application. Google Calendar permissions, if granted, are used to support authorized household scheduling and calendar coordination.

Family Planner is not an AI imagery application and does not use Google APIs for AI NCII. The project uses Google APIs for authentication and authorized calendar functionality only.

3. Data storage and retention

This public GitHub Pages website stores only static documentation and does not process sign-ins, collect account data, or store user calendar data.

The private Family Planner application is responsible for storing any account data, OAuth tokens, household information, and calendar data it uses. The exact storage location, database, backup process, and data retention period must be confirmed by the owner before final publication.

4. Data sharing

This public website does not sell or share personal information for advertising or analytics. The private application must confirm whether any data is shared with third parties, infrastructure providers, backup systems, or other vendors.

5. Account and data deletion

Users may revoke Google access through their Google Account security settings and connected-app permissions page.

If the private application stores account or household data, the owner must provide the actual account deletion and data erasure process and the relevant contact method for deletion requests.

6. Privacy contact information

This public site does not currently publish a verified user-facing privacy contact address. The owner must confirm the final email address or contact method before the policy is treated as a final published privacy notice.

7. Google API Services User Data Policy

The Family Planner project uses Google APIs for authentication and authorized calendar functionality only. The application owner is responsible for confirming that the final implementation remains compliant with Google’s API Services User Data Policy and the relevant Google account permissions requirements.

8. Information requiring owner confirmation before final publication

  • Exact Google OAuth scopes and Calendar scopes used by the app
  • Whether Google Calendar access is read-only or write-capable
  • Which Google account and Calendar fields are actually stored
  • Where OAuth tokens, account records, and household data are stored
  • Retention period for user data and calendar data
  • How account deletion and data erasure are handled
  • Whether any data is shared with third parties or backups
  • Verified privacy contact information

Until the owner confirms each item above, this page should be treated as a draft public notice only. Do not publish it as a final policy without those facts being confirmed.
