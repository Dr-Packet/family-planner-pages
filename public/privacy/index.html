Privacy Policy

Family Planner is a private family dashboard for household routines, chores, rewards, and shared scheduling. This repository contains the public documentation and verification pages for the project. The actual Family Planner application and its Google OAuth implementation are not hosted in this repository.

1. Scope of this notice

This public policy is intentionally limited to the information available in this repository. The actual Google OAuth and Calendar configuration, storage location, retention policy, and deletion process must be confirmed by the app owner before this notice is published as a final product privacy policy.

2. Google data that may be involved

When Google sign-in is enabled, Family Planner may rely on Google account information returned by Google’s sign-in flow, such as the user’s Google account identifier, email address, and profile details that Google makes available to the app. The exact data returned depends on the OAuth configuration and the scopes granted by the user.

If Google Calendar access is enabled, the app may request one or more Calendar API scopes to read calendar data or to create, update, or manage calendar entries. The exact scopes, event fields, and whether the app can write to calendar data must be confirmed by the owner before publication.

3. Why this data is used

Google account information may be used to identify the user and allow access to the private Family Planner application. Calendar access, if enabled, may be used to display or coordinate household scheduling, reminders, or shared events. The exact purpose for each data element must be confirmed by the app owner before a final policy is published.

4. Where data is stored

This public GitHub Pages site stores only static documentation and does not store user accounts, OAuth tokens, or calendar data.

The actual Family Planner application and any data it stores are managed outside this repository. The exact storage location, database system, and hosting environment must be confirmed by the owner before the final privacy policy is published.

5. Calendar data and persistence

This repository does not document whether any Google Calendar data is cached, stored, or persisted by the private app. If the application stores or copies calendar data, the owner must confirm which event fields are retained, where they are stored, and whether they are kept in a database or a cache.

6. Retention and deletion

The public GitHub Pages site does not retain personal data. The private Family Planner application’s retention period for Google account data, OAuth tokens, and any calendar data is not documented in this repository.

The owner must confirm the actual retention schedule, deletion process, and any automated cleanup rules before publication. Users may revoke Google access through their Google Account security settings. The app owner must also confirm the user-facing deletion process for account removal and data erasure inside the private application.

7. Sharing and disclosure

This public site does not sell, trade, or share personal information for advertising or analytics. Any sharing of personal data by the private Family Planner application depends on its actual implementation and hosting configuration, which is not documented in this repository.

The owner must confirm whether data is shared with third-party services, infrastructure providers, backups, or vendors before a final policy can be published.

8. Security

The public GitHub Pages site is static HTML and does not process user sign-ins or tokens. The private Family Planner application’s security protections, including access controls, encryption, API protections, and token storage, are not documented in this repository.

The owner must confirm the actual security measures before a final privacy policy is published.

9. User controls and privacy requests

Users can revoke Google access by visiting the Google Account permissions page and removing Family Planner from the connected apps list.

To request deletion of any account or family data stored by the private app, users must use the contact method published by the application. This repository does not currently include a verified privacy contact address.

10. Contact

For questions about this project or privacy requests, use the contact method published on the Family Planner application or on the owner’s final public product site. This repository does not include a verified user-facing contact address.

11. Facts that must be confirmed before publication

  • Exact Google OAuth scopes and Calendar scopes used by the app
  • What Google account data and Calendar fields are accessed
  • Why each data category is required for the app to function
  • Where OAuth tokens and account information are stored
  • Whether Calendar data is cached, copied, or persisted
  • Actual retention periods and deletion procedures
  • Whether any data is shared with third parties or vendors
  • Actual security controls implemented by the private app
  • How users revoke Google access and request account deletion
  • Real privacy contact information for user support

This notice is intentionally conservative and avoids unsupported claims. Once the owner confirms the implemented app behavior, this text can be updated to match the actual product and published as a final privacy policy.
